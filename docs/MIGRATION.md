# 双线并行与切换条件

旧版继续保留，供使用和验证任务流程；本仓库维护框架资源实现。业务变更先写明确的输入、成功证据与失败行为，再在两边分别验收，不能因为旧版通过就认定新版通过。

第一阶段：仅每日签到并返回桌面。第二阶段：通过验收后发布可安装预览版。第三阶段：稳定候选版本达到以下条件后，再将主要开发和分发入口切换过来。

- 实机验证当天未领取→领取→确认→返回桌面；另日复验。
- 已领取时不重复点击；未知弹窗、断连、取消和超时均能结束并留日志。
- 全新安装及升级、Shizuku 授权失败提示通过。
- 正式签名妥善保存，APK 与完整对应源码可获取。
- 旧版保留存档，发布迁移说明；不删除、不停用旧版。

第一轮只验收前台模式。虚拟屏幕、定时与解锁各自单独验收，不计入首次切换的必要条件。

## 2026-10-07 业务迁移顺序

以自研版cfc0c3f为当前行为参考。迁移的是任务语义与成功证据，控件树坐标不能直接作为OCR点击坐标。

| 顺序 | 迁移内容 | 框架适配与验收 |
| --- | --- | --- |
| 1 | 签到→快速赚总完成→HOME | 已加入独立实验Pipeline；14项离线测试通过，需真实OCR样本和手机验收 |
| 2 | 已知广告关闭与前台入口 | 券弹窗当前关闭按钮是无文字控件，需要真实裁图模板和弹窗标题双确认；底座16:9入口限制单独适配，不改变用户屏幕尺寸 |
| 3 | 趣味课堂与题库 | 完整题目与答案文字共同识别，选择状态核对后提交一次；领奖文案与面板奖励消失均验证；未知题停止 |
| 4 | 视频及搜索浏览 | 任务标题会动态改变；识别实际进入页面和计时徽章，分段滑动；已得30即结束，不点击下单再得500 |
| 5 | 庄园访问返回 | 控制器确认支付宝包和庄园标题后返回淘宝；用面板完成状态确认，不在庄园点击游戏或授权 |
| 6 | 整体执行与诊断 | 单任务最长停留60秒、总任务预算、截图时间和停止原因；用实机验证后台挂起时截止，不只依赖单元测试 |

题库唯一维护来源暂为自研仓库docs/QUIZ_BANK.md；迁移课堂时生成框架资源并测试，避免两套答案手工漂移。截图属于个人数据，只放本地忽略目录，测试不上传完整手机页面。

首次稳定切换需要在不同日期验证未领与已领完整分支，以及未知题、弹窗、超时和取消；不能把离线Pipeline测试或自研真机通过当成框架已通过。第一版只验证前台，定时、解锁与虚拟屏另行验收。
