# 双线并行与切换条件

旧版继续保留，供使用和验证任务流程；本仓库维护框架资源实现。业务变更先写明确的输入、成功证据与失败行为，再在两边分别验收，不能因为旧版通过就认定新版通过。

第一阶段：仅每日签到并返回桌面。第二阶段：通过验收后发布可安装预览版。第三阶段：稳定候选版本达到以下条件后，再将主要开发和分发入口切换过来。

- 实机验证当天未领取→领取→确认→返回桌面；另日复验。
- 已领取时不重复点击；未知弹窗、断连、取消和超时均能结束并留日志。
- 全新安装及升级、Shizuku 授权失败提示通过。
- 正式签名妥善保存，APK 与完整对应源码可获取。
- 旧版保留存档，发布迁移说明；不删除、不停用旧版。

第一轮只验收前台模式。虚拟屏幕、定时与解锁各自单独验收，不计入首次切换的必要条件。
