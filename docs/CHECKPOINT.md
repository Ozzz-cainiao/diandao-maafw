## 恢复顺序

1. 看 Git 状态与 Actions 构建结果；本地构建日志在 .cache/build.log（不提交）。
2. 构建成功后检查 APK 内包名、资源与 ABI，制作开发预览包；不要标稳定版。
3. 有手机时先验证已领取分支及返回桌面，再跨天验证新领取分支；逐项保存去敏结果。
4. 初次闭环后再考虑定时/虚拟屏幕，不同时扩展快速赚。
