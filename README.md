# 点到实验版

Android 自动签到工具的新实现，与现有点到短期并行。支持每日淘金币签到，以及签到后核对快速赚总完成状态。

**当前为开发版本，尚未完成真机领取验收，不建议设置无人值守任务。**

## 使用准备

1. Android 9 或以上，安装淘宝并手动登录。
2. 安装并启动 [Shizuku](https://shizuku.rikka.app/guide/setup/)，授权点到实验版。
3. 按应用提示配置通知与电池权限，首次测试选择前台模式。
4. 保持解锁，手动回到淘宝首页并关闭弹窗，运行“淘金币签到并返回桌面”。
5. 查看运行日志。识别超时请人工确认页面，不要连续重复尝试。

实验版包名为 `com.aliothmoon.maafw.diandao`，可与旧版同时安装。首次迁移不会转移旧版设置。

## 当前范围

每日签到只点击一次并核对页面标记。新增实验任务“签到并核对快速赚完成状态”：只有页面显示今日快速赚奖励已拿完才返回桌面；待领取或识别不明会停止。目前不执行快速赚子任务、支付、转账或验证码操作。成功后发送返回桌面指令，不强制结束淘宝。

当前识别基于屏幕文字，页面变化和广告遮挡可能造成失败。定时、虚拟屏幕和自动解锁尚未作为本项目验收能力。
